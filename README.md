# Telegram Shop Bot (Stars · Gifts/NFT · TON · VPN · Донат)

aiogram 3 + PostgreSQL + CryptoBot (пополнение) + Marzban (VPN).

## Деплой на Railway
1. Залей проект в GitHub → Railway → New Project → Deploy from GitHub.
2. Add → Database → PostgreSQL (переменная `DATABASE_URL` подставится сама; если нет — Variables → Add Reference).
3. (Опционально) Add → Redis и `REDIS_URL`.
4. Variables: `BOT_TOKEN`, `ADMIN_IDS`, `ADMIN_CHAT_ID`, `CRYPTO_TOKEN`, `MARZBAN_*` (см. `.env.example`).
5. Запуск уже настроен в `railway.json` (`python -m bot.main`). Бот работает на long polling, домен не нужен.

## Как это работает
- Пользователь пополняет баланс (CryptoBot, счёт в ₽) → покупает товар с баланса.
- **VPN**: товар типа `vpn` выдаётся автоматически через Marzban (создание/продление, ссылка-подписка).
- **Звёзды, подарки, NFT, TON, удалённые подарки, донат**: заказ падает в админ-чат с кнопками «✅ Выполнено» / «❌ Отказ + возврат». Покупатель получает уведомление и просьбу оставить отзыв.
- Отзывы публикуются в канал (`REVIEWS_CHANNEL_ID`), топ-3 покупателей получают скидку, рефералка начисляет % с пополнений.
- Поддержка: сообщение пользователя копируется в админ-чат, ответ — реплаем на него.

## Админка
`/admin`: статистика, заказы в работе, категории/товары (цена, остаток, скрыть), рассылка.
Команды: `/addbalance id сумма`, `/ban id`, `/unban id`.
Товар с «вопросом покупателю» (например «Введите @username») спрашивает данные перед оплатой.
